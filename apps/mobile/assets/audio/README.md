# TV 모달 효과음

- `tv-on.wav`: 340ms. 전원 클릭, 상승하는 전자음, 약한 CRT 잡음.
- `tv-off.wav`: 240ms. 하강하는 전자음, 화면이 점으로 줄어드는 160ms 지점의 전원 클릭.
- 44.1kHz / mono / 16-bit PCM WAV. 최대 진폭 0.55, 양 끝 fade 적용.
- 외부 음원·샘플을 사용하지 않고 이 프로젝트에서 직접 합성한 에셋. 별도 출처 표시나 외부 라이선스 비용 없음.
- 재생성: 저장소 루트에서 `node apps/mobile/scripts/generate-tv-sounds.mjs`.

## 전체 게임 오디오

- 생성: `node apps/mobile/scripts/generate-game-audio.mjs` (macOS `afconvert` 사용).
- 외부 샘플 없이 직접 작곡·합성한 16마디 chiptune BGM 6곡과 짧은 효과음 12종. 기존 TV 2종 포함 전체 20개 음원, 약 2.3MB.
- BGM: mono AAC 44.1kHz/64kbps. 효과음: mono PCM WAV 44.1kHz/16bit. 끝점 fade로 클릭 노이즈 방지.

| relay   | 모드2 제시어·그림·정답 작성          | 108 |

| award   | 모드1 시상식·모드2 종료              | 112 |

| -------------------------- | ------------------------------------------------------------------------------------------------ |

- 게임 결과는 `roundResult`에서 한 번만 재생. `chat:correct`와 이중 재생하지 않음.
- 역할별 정답 피드백: 본인 정답·출제자에게 성공 햅틱, 다른 참가자는 낮은 음량의 소리만.
- 오답은 110ms 간격의 짧은 햅틱 두 번. 기본 버튼은 한 번, 타이머 틱은 소리만.
- 동일 게임/라운드/메시지 키 중복 방지, UI 80ms 연타 제한, 결과음 우선. TV 효과는 기존 90ms/160ms 햅틱 타이밍 유지.
- BGM 1개·효과음별 플레이어 공유. 같은 화면군은 재시작하지 않고 전환 시 200ms fade-out. 결과 연출 동안 BGM 30%로 duck.
- BGM·효과음·햅틱 개별 ON/OFF, BGM/효과음 볼륨을 SecureStore에 저장. 기존 TV 설정 복원 호환.
- 스플래시·강제 업데이트 중 BGM 없음. 기기 무음 모드 존중, 백그라운드에서 소리와 예약 햅틱 중단, 복귀 시 BGM만 재개.
- 채팅 수신·펜 스트로크·매초 햅틱·친구 온라인 알림은 반복 피로 때문에 제외. 긴박 BGM 변주 대신 마지막 10초 틱 사용.
