# 스케치캐치 앱 — 프로젝트 인덱스

이 폴더는 Claude Code를 팀원으로 운영하기 위한 역할별 컨텍스트 문서입니다.
각 작업을 시작할 때 **해당 역할 문서 1개를 컨텍스트로 주입**하면, Claude Code가 그 역할로 자율적으로 일합니다.

## 프로젝트 한 줄 소개
실시간 멀티플레이어 스케치캐치. 픽셀아트 테마. React Native(Expo) + Node.js(Socket.io). 모드 2종(클래식/전언게임).

## 역할별 문서

| 파일 | 역할 | 사용 시점 |
|---|---|---|
| `01_기획자.md` | 제품 기획자 | 기능 정의, 사용자 시나리오, 정책 결정 |
| `02_디자이너.md` | UI/UX + 픽셀아트 디자이너 | 디자인 시스템, 캐릭터/사운드 에셋 제작 |
| `03_개발자.md` | RN + Node.js 풀스택 개발자 | 구현, 아키텍처, API, 실시간 동기화 |
| `04_QA.md` | 모바일 게임 QA 엔지니어 | 테스트 케이스 작성, 회귀 검증, 엣지 케이스 |

## 사용 방법 (Claude Code 운영)
1. 작업 종류에 맞는 역할 문서를 열어 컨텍스트로 제공한다.
2. 작업 지시는 해당 역할 범위 안에서 내린다 (예: 디자이너 문서 + "캐릭터 20종 AI 생성 프롬프트 만들어줘").
3. 다른 역할의 결정이 필요한 부분이 나오면 Claude Code가 멈추고 질문하도록 각 문서에 명시되어 있다.

## 핵심 결정 사항 (전 역할 공통)
- **인증**: iOS는 카카오 + 애플, 안드로이드는 카카오만
- **방 입장**: 6자리 방 코드 (딥링크 아님)
- **푸시 알림**: Expo Push Notifications 사용
- **AI 이미지 생성**: 캐릭터/배경/아이콘은 Gemini 등 AI로 제작
- **사운드**: Pixabay, Mixkit 등 무료 라이선스(CC0/상업이용 가능)만 사용
- **비속어 필터**: 한국어 전용 npm 라이브러리 + 자체 사전 보강
- **GIF 변환**: 서버 자체 구현 (`node-canvas` + `gifenc`), 외부 과금 API 사용 금지
- **언어**: 한국어 전용
