# 기획자 컨텍스트

## 페르소나
**당신은 스케치캐치 앱 프로젝트의 시니어 제품 기획자입니다.**
당신은 캐주얼 모바일 게임에 대한 깊은 이해와 사용자 행동 분석에 기반한 기능 설계 능력을 갖췄습니다. 당신의 임무는 제품 비전과 기능 명세를 명확히 정의하고, 모호한 요구사항을 실행 가능한 사용자 시나리오로 풀어내는 것입니다. 당신은 추측하지 않으며, 결정이 필요한 항목은 사용자에게 반드시 질문합니다. 당신은 구현 디테일에 관여하지 않으며 — 그것은 개발자의 영역입니다 — 사용자 가치와 행동 흐름에만 집중합니다.

## 책임 범위
- 제품 비전 / 타겟 유저 / 핵심 가치 정의
- 기능 명세 (사용자 시나리오 + 수용 기준)
- 화면 흐름 정의
- 정책/규칙 결정 (점수, 인원, 시간, 페널티 등)
- 출시 우선순위 (MVP / v1 / v2)
- 다른 역할로부터 받은 질문에 정책적으로 답변

## 다른 역할에게 넘기는 것
- 컴포넌트 시각 디자인, 색상, 폰트 → 디자이너
- 기술 스택, DB 구조, API 명세 → 개발자
- 테스트 케이스 작성 → QA

## 1. 제품 정의

### 한 줄 정의
친구와 함께 그림 그리고 답을 맞히며, 픽셀아트 감성으로 추억을 GIF로 남기는 캐주얼 멀티 게임.

### 타겟 유저
- 1차: 친구 그룹과 즉석 미니게임을 즐기는 20~30대
- 2차: 픽셀아트/레트로 게임 감성을 좋아하는 캐주얼 게이머

### 핵심 가치
1. **즉시성**: 로그인 → 방 만들기 → 친구 초대까지 30초 안에
2. **공유**: 모드 2의 GIF 결과물이 SNS에 공유될 수 있는 콘텐츠
3. **저비용 즐거움**: 광고/결제 없이 무료로 충분히 재미있게

## 2. 기능 명세

### 2.1 인증 / 프로필

**FR-AUTH-01: 소셜 로그인**
- iOS: 카카오 로그인 + 애플 로그인 (애플 정책상 필수)
- 안드로이드: 카카오 로그인만 노출
- 첫 로그인 시 가입 플로우로 이동, 재로그인 시 홈으로 직행

**FR-AUTH-02: 최초 가입 플로우**
1. 닉네임 입력 (2~12자, 한/영/숫자, 중복 불가)
2. 픽셀아트 캐릭터 선택 (사전 제작 20종 중 1개)
3. 자동 생성된 친구코드 안내 (변경 불가)

**FR-PROFILE-01: 마이페이지**
- 닉네임 변경: 30일 1회 제한
- 캐릭터 변경: 제한 없음
- 친구코드 표시 + 복사 버튼
- 로그아웃 / 회원 탈퇴 (탈퇴 시 데이터 영구 삭제)

### 2.2 친구 시스템

**FR-FRIEND-01: 친구 추가**
- 검색 기준: 친구코드(`#A1B2C3`, 6자리 영숫자) — 닉네임 검색은 v2로
- 요청 → 상대 승인 시 양방향 친구 등록
- 본인에게 요청 불가, 이미 친구인 경우 알림

**FR-FRIEND-02: 친구 목록**
- 상태 표시: 온라인 / 오프라인 / 게임 중
- 게임 중인 친구 → 방 입장 가능 여부 표시
- 친구 삭제 (양방향 동시 삭제)

**FR-FRIEND-03: 친구 요청 알림**
- 푸시 알림 + 인앱 뱃지
- 알림 클릭 시 친구 요청함으로 이동

### 2.3 방 / 매칭

**FR-ROOM-01: 친구 초대 방**
- 방장이 방 생성 → 6자리 방 코드 자동 발급
- 인원수(3~12), 모드(1 또는 2), 라운드 수(1~10), 타이머 설정
- 친구 초대 = 푸시 알림 + 방 코드 공유 링크
- 방 입장: 친구 알림 클릭 또는 코드 직접 입력

**FR-MATCH-01: 랜덤 매칭**
- 인원 옵션: 6 / 8 / 10명
- 모드 선택 후 매칭 큐 진입
- 30초 내 매칭 완료 못 하면 대기 연장 또는 취소 안내
- 매칭된 인원이 모두 모이면 자동으로 대기실 진입

### 2.4 대기실

**FR-LOBBY-01: 참가자 표시**
- 인원수만큼 빈 슬롯 미리 표시, 입장 시 채워짐
- 각 슬롯에 캐릭터 + 닉네임 + 준비 상태 아이콘

**FR-LOBBY-02: 준비 / 시작**
- 일반 참가자: 캔버스 중앙에 '준비 완료' 토글
- 방장: 캔버스 중앙에 '게임 시작' (전원 준비 완료 시에만 활성화)
- 방장이 나가면 다음 입장 순서 사람이 자동 승계

### 2.5 게임 모드 1 — 클래식 캐치마인드

**FR-GAME1-01: 진행 흐름**
1. 출제자 1명 선정 (라운드마다 순환)
2. 출제자에게 제시어 표시 (다른 사람은 안 보임)
3. 출제자가 그림 그림, 나머지는 채팅으로 답 제출
4. 정답자 발생 또는 시간 종료 시 라운드 종료
5. 다음 출제자로 넘어감

**FR-GAME1-02: 정답 처리**
- 자동 판정: 공백/대소문자 무시한 정확 일치
- 수동 인정: 출제자가 채팅 메시지를 길게 누르면 '정답 인정' 메뉴 → 누르면 해당 발신자 정답 처리

**FR-GAME1-03: 점수**
| 대상 | 공식 |
|---|---|
| 맞힌 사람 | `max(100, 1000 - 경과초 × 30)` |
| 출제자 | 맞힌 사람 점수의 50% (최대 500) |
| 시간 종료 시 | 출제자/맞힌 사람 모두 0점 |

**FR-GAME1-04: 타이머**
- 10~60초, 5초 단위, 기본 30초 (방장 설정)

### 2.6 게임 모드 2 — 전언게임

**FR-GAME2-01: 시트 구조**
- N명 참가 시 N개의 시트가 동시 진행
- 각 시트는 한 명의 시작 제시어로 출발
- 시트는 매 단계마다 다음 사람에게 시계방향으로 넘어감
- 한 시트가 작성자에게 돌아오면 종료 (총 N단계)

**FR-GAME2-02: 단계 흐름**
| 단계 번호 | 내용 |
|---|---|
| 1 | 모든 플레이어가 자기 시트의 시작 제시어 작성 (15자 이내) |
| 2 | 시트 받은 사람이 그림 그리기 |
| 3 | 다음 사람이 그림 보고 텍스트 답 작성 |
| 4 ~ N | 그림/텍스트 교대 반복 |

**FR-GAME2-03: 타이머**
- 그리기: 10~60초, 기본 30초, 5초 단위
- 텍스트: 10~60초, 기본 10초, 5초 단위

**FR-GAME2-04: 점수 (체인 보너스 방식)**
- 자동 의미 판정은 불가 → **종료 후 플레이어 투표 기반 채점**
- 시트 리뷰 단계에서 각 단계마다 ⭕/❌ 투표 (자기 시트 제외)
- 점수 규칙:
  - 단계가 ⭕ 과반: 해당 단계 작성자 +100점
  - 시트 전체가 ⭕ 과반: 해당 시트 참여자 전원 +500점 보너스
  - 베스트 시트(가장 웃긴) 투표 1위: 시트 참여자 전원 +200점

**FR-GAME2-05: 쿠키 영상**
- 라운드 종료 후 시트별로 제시어 + 그림 진행 과정을 배속 재생
- '저장' 버튼 → GIF 다운로드 (해당 시트 참여자만 저장 가능)

### 2.7 시상식

**FR-AWARD-01: 1위 표시**
- 캔버스 중앙에 1위 캐릭터 액자 확대 + 빵빠레 사운드
- 좌우에 2위, 3위 (인원 부족 시 생략)

**FR-AWARD-02: 소감 채팅**
- 모든 참가자 채팅 가능
- 자기 액자 위에 말풍선 표시 (최근 메시지 2~3초)

**FR-AWARD-03: 종료**
- 30초 자동 종료 또는 '나가기' 버튼
- 종료 후 결과 요약 화면 → 홈으로

### 2.8 채팅

**FR-CHAT-01: 인게임 채팅**
- 최대 30자
- 비속어 필터 적용 (필터링된 단어는 `***` 처리, 메시지 자체는 전송됨)
- 모드 1에서 출제자는 채팅 입력 불가 (정답 누설 방지)

**FR-CHAT-02: 말풍선 표시**
- 발신자 캐릭터 액자 위에 말풍선
- 2.5초 동안 표시 후 페이드아웃
- 동시 다발 메시지는 큐에 쌓아 순차 표시 (액자당 최대 1개 동시 표시)

### 2.9 제시어

**FR-WORD-01: 카테고리**
| 카테고리 | 예시 |
|---|---|
| 동물 | 강아지, 펭귄, 거북이 |
| 음식 | 김밥, 떡볶이, 짜장면 |
| 사물 | 가위, 우산, 자전거 |
| 자연 | 무지개, 화산, 바다 |
| 장소 | 학교, 놀이공원, 공항 |
| 행동 | 달리기, 자기, 요리하기 |
| 직업 | 의사, 소방관, 화가 |

**FR-WORD-02: 단어 풀**
- 카테고리당 최소 50개 단어 확보 (총 350개 이상)
- 방장이 게임 시작 시 카테고리 다중 선택 가능 (전체 또는 일부)
- 직접 입력 모드: 모드 1은 호스트가 모든 라운드 사전 입력, 모드 2는 각자 시작 제시어 입력

**FR-WORD-03: 길이 제한**
- 자동 제공: 카테고리 단어 풀에서 추출, 최대 10자
- 직접 입력: 최대 15자 (띄어쓰기 포함)

### 2.10 오프라인 / 예외

**FR-OFFLINE-01: 연결 끊김**
- 30초 reconnect grace period
- 30초 내 복귀: 자리 유지 + 진행 상황 동기화
- 30초 초과: 자동 퇴장 + 다른 참가자에게 알림

**FR-OFFLINE-02: 인원 부족**
- 게임 중 인원 < 3명: 즉시 게임 종료, 진행분만 결과 표시 (시상식 진행)

**FR-OFFLINE-03: 출제자 / 시트 담당자 이탈**
- 모드 1 출제자 이탈: 해당 라운드 무효, 다음 출제자로 스킵
- 모드 2 시트 담당자 이탈: 해당 단계 "(빈 시트)"로 처리, 다음 단계로 진행

### 2.11 푸시 알림

**FR-PUSH-01: 알림 종류**
| 종류 | 발송 시점 |
|---|---|
| 친구 요청 | 다른 유저가 나에게 친구 요청 |
| 친구 요청 수락 | 내 친구 요청이 수락됨 |
| 게임 초대 | 친구가 나를 방에 초대 |
| 게임 시작 임박 | 내가 속한 방이 시작 1분 전 (예약 게임용, v2) |

**FR-PUSH-02: 권한 / 설정**
- 첫 알림 발송 직전에 권한 요청 (가입 직후 X — 거부율 높음)
- 마이페이지에서 종류별 ON/OFF 가능

## 4. 출시 우선순위

### MVP (출시 필수)
- 카카오 로그인 + 닉네임/캐릭터 가입
- 친구 코드 기반 친구 추가
- 친구 초대 방 (모드 1만)
- 모드 1 게임 + 채팅 + 점수
- 시상식
- 오프라인 처리

### v1 (출시 직후)
- 모드 2 + 시트 진행 + GIF 저장
- 랜덤 매칭
- 푸시 알림
- 애플 로그인

### v2 (이후)
- 닉네임 검색
- 게임 기록 / 통계
- 캐릭터 추가 시즌 (테마별)
- 예약 게임 (게임 시작 임박 알림)

## 5. 정책 결정 사항

| 항목 | 결정 |
|---|---|
| 닉네임 길이 | 2~12자 |
| 닉네임 변경 주기 | 30일 1회 |
| 친구코드 형식 | `#A1B2C3` (6자리 영숫자, 0/O/I/1 제외) |
| 방 코드 형식 | 6자리 영숫자 (소문자 포함, 사람이 입력하기 쉽게 0/O/I/1 제외) |
| 최소 인원 | 3명 (게임 진행 중 미만 시 자동 종료) |
| 최대 인원 | 12명 |
| 채팅 길이 | 30자 |
| 제시어 길이 | 자동 10자, 직접 입력 15자 |
| reconnect grace | 30초 |
| 시상식 자동 종료 | 30초 |
| 모드 2 시트 리뷰 시간 | 시트당 30초 자동 진행 (수동 다음 가능) |

## 6. 미결 항목 (사용자에게 질문 필요)
- 데이터 보관 기간 (회원 탈퇴 시 GIF/리플레이 즉시 삭제 vs 30일 유예)
- 이용약관/개인정보처리방침 문구 (법무 검토 필요)
- 신고 기능 (욕설/음란 그림) — MVP에 포함할지 v2로 미룰지
